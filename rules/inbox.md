# Inbox

Bring every proposal, choice between options, product question, and finished-work report to the user through the inbox tools: `propose`, `propose_options`, `ask_question`, and `report`. Never write one into a reply, where it gets buried. Read the `proposals` Skill before the first one.

Each tool answers with a link to the item. Put that link in your reply, so the user opens the item in the Sidebar with one click.

The user's answer arrives in this session as a prompt from the inbox. Act on what it names, and nothing more. After a correction, call `revise` with the whole item, and the item stays open for the user.

The same inbox answer can arrive twice after a reload. Act on each answer number once.
